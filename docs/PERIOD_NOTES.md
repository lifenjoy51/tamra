# 시대 자료 — 5세기 후반 동양 항해술

> Tamra의 시대 앵커(476년 탐라 → 백제 조공)와 같은 시기 동아시아 항해술의 사실 정리. 각 항목 끝의 **→ 적용**은 이 사실이 프로젝트의 어떤 결정·시스템·Tier의 *역사적 근거*가 되는지 색인.

시대 결정 배경은 [project memory](../.claude/projects/-Users-lifenjoy51-works-tamra/memory/project_setting_era.md), 향후 과제는 [ROADMAP.md](ROADMAP.md), UI 가드레일은 [UI_PLAN.md](UI_PLAN.md).

## 1. 시대 정세 (450~500)

- **중국**: 남북조. 남조 송(420-479) → 제(479-502). 남조는 인도·동남아·한반도와 활발히 해상 교류.
- **백제**: '해상 강국'. 한성 함락(475) → 웅진 천도. 그러나 서해를 가로질러 남조와 긴밀 통교, 요서 영향력설.
- **신라·가야**: 발흥기. 가야는 후기 연맹(대가야 중심)으로 활발한 해상 교역.
- **왜**: 왜 5왕 시대. 478년 왜왕 무가 송 순제에 표문.
- **탐라**: 476년 백제에 조공. 동아시아 해상 네트워크 공식 편입.

→ **적용**: 시대 한정 가드레일. 9세기 이후(장보고/청해진/통일신라) 인용 금지. ROADMAP Tier 4.1 역사 컨텍스트의 톤 결정 근거.

## 2. 자석 도구의 위상 — *항해용으로 거의 쓰이지 않음*

5세기 동양은 자석의 지남성을 알고 있었으나 항해엔 거의 무용:

- **사남(司南)**: 한대 이래 천연 자석 숟가락. 지반 위 회전. 마찰력 커서 *흔들리는 선상에 부적합*.
- **지남차(指南車)**: 톱니바퀴 기반 기계. *육상 안개 속 방향용*. 해상 도입 증거 없음.
- 4~5세기에 회전 바늘형 초기 지남반 존재했으나 **풍수·점술·의례용**에 머물렀고, *해상 항해용 나침반은 11세기 송대 이후 출현*.

→ **적용**: DESIGN.md "나침반/방위 라벨 거부" 가드레일의 *역사적 정당성*. ROADMAP Tier 3 항법 보조 도구의 시대 범위 한정 (별·태양·새·해류·지형만).

## 3. 천문 항법 — 북반구의 고정 이정표

- **북극성·북두칠성**: 북반구 항해의 핵심 지표. 사남의 형상 자체가 북두칠성 모티브일 만큼 동양 방위 측정의 상징.
- **별 고도 측정**: 별의 지평선 위 고도로 *위도 가늠*. 5세기 동아시아도 정밀 별자리 관측 능력 보유 (신라·백제의 천문 관측 기록).
- **태양 관측**: 주간 남북 결정.

→ **적용**:
- ROADMAP **Tier 3.1 별 고도 측정기**의 직접적 역사 근거. *손가락 폭/기준 별 비교*는 동·서 공통 원시 도구.
- 현 시스템 `astronomy/stars.ts` 의 STARS 카탈로그에 **북극성·북두칠성 우선 가시성** 보장 필요(별 고도 측정 UX의 기준 별).
- ROADMAP **Tier 3.2 일출/일몰 방위**: 태양 관측이 주간 항법의 핵심이라는 사실과 정합.

## 4. 기상·해류 항법 — *바람과 물에 순응*

- **계절풍(Monsoon)**: 11세기 나침반 도입 전까지 동양 항해를 지배. 여름 남풍 → 북상, 겨울 북풍 → 남하. *항해 일정 자체가 풍기에 종속*.
- **쿠로시오(흑조)**: 한반도-일본-중국 항로의 천연 '고속도로'. 백제 선단이 흐름을 읽어 침로 결정.

→ **적용**:
- 현 `physics/wind.ts` 의 **아시아 몬순(여름 SW / 겨울 NE)** 모델이 시대 정합 ✅. 계절감 강화는 시대 적합.
- 현 `physics/current.ts` 의 **쿠로시오 패치(110~150°E, NE 1.2 m/s)** 가 5세기 항해사가 *실제로 활용한* 해류임 — 단순 시뮬 디테일 아니라 *시대 정합* 요소 ✅.
- 시나리오 항로(ROADMAP 1.1) 설계 시 **계절을 명시**해야 함 (예: 탐라→남조 항로는 *여름 남풍 시작* 시기 출발이 자연스러움).

## 6. 백제 사례 — 시나리오 설계 근거

- **490년(동성왕 12년) 북위 기병 격퇴** (《남제서》 백제전). 실체 논란이 있으나, *서해 횡단 대선단 운용 능력*의 방증.
- **사단 항로**: 한반도 서해안 → 산둥반도/양쯔강 하구. **해류·지형 관측 기반** 항법.
- **선박**: 원양 가능 대형선 또는 *두 척을 이은 방(舫)* 형태로 안정성 확보.

→ **적용**:
- ROADMAP 1.1 시나리오 "탐라 → 남조(명주·양쯔강 하구)"는 *백제 매개 사단 항로*의 탐라발 변형. 역사적 정당성 확보.
- 시나리오 "탐라 → 백제 웅진"은 476년 조공 항로의 직접 재현.
- 선박 표현(B.1 펜넌트 / B.2 돛 변형 작업 시) **방(舫) 쌍동선 형태 고려** — 단동선보다 시대 정합.

## 7. 법현(法顯)의 기록 — 표류와 가시성

5세기 초 법현의 인도→스리랑카→중국 해로 귀환 기록:

> "밤에는 별을 보고 낮에는 태양을 보며 항해하되, 날이 흐리면 방향을 잃고 표류할 수밖에 없었다"

→ **적용**:
- ROADMAP **Tier 2.4 표류 메커닉**의 *직접 일차 사료 근거*. "흐린 날=방향 상실=표류"는 5세기 항해의 실재 위험.
- 현 `weather.cloudiness` + `visibilityCoef` 는 **단순 시각 효과를 넘어 게임 메커닉으로 격상**되어야 함:
  - cloudiness > 0.7 동안 별·태양 가시성 저하 → Tier 3.1 별 고도 측정 불가
  - 그 상태로 N시간 지속 → 표류 상태 진입(Tier 2.4)
- 이는 단순 페널티가 아니라 *역사적 항해 위험의 시뮬*. 토스트 알림 톤 예: "구름이 두텁다. 별이 보이지 않는다."

## 8. 종합 — '도구의 결핍을 지식의 고도화로 극복'

5세기 후반 동양 항해는 **나침반 없이도** 별 고도 변화, 계절풍 도래 시기, 바다 색·해류 미묘한 흐름을 *극도로 정교하게* 읽어 동아시아 해상 네트워크를 운영했다. 이 축적된 지식이 11세기 나침반 도입 후 *24방위 체계*로 즉시 발전할 수 있었던 자양분.

→ **프로젝트 핵심 메시지와 정합**: DESIGN.md "배 위의 사람" — *도구가 적기에 더 많은 단서를 읽어야 한다*는 게임의 본질이 곧 5세기 항해 그 자체. 역사 정당성과 게임 컨셉이 동일선상.
