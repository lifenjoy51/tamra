# 5세기 후반 해상 교역망과 항구 노드

> 탐라(제주)를 중심으로 한 5세기 후반 동아시아 해상 교역망의 *항구·항로·상품 흐름* 사실 정리. **시나리오·항구 데이터(ROADMAP Tier 1.1, 4.2)의 일차 근거**. 항해술 사실은 [PERIOD_NOTES.md](PERIOD_NOTES.md), 시대 정세는 거기 §1.

---

## 핵심 명제 — 탐라 = "릴레이 노드"

탐라는 장거리 원양 항해의 단일 종착항이 *아니라*, 제주 북부 포구권을 중심으로 영산강 하구 → 가야 남해안 → 대마·이키·무나카타 → 난바로 이어지는 **다층 중계망의 한 노드**.

> "광저우-탐라 직항"보다 **영산강/가야 ↔ 탐라 ↔ 북규슈**의 *계단식 릴레이*가 기본값.

→ **게임 적용**:
- 시나리오는 *짧은 구간 연쇄* 구조가 본질. 단일 장거리 직항만 만들면 사료에 어긋남.
- 탐라발 시나리오의 가장 현실적 1순위는 **영산강 하구**(가장 안정적 근접 축).
- 남조(중국)·왜(일본)는 *경유 노드* 구조로 표현 — 직항 시나리오는 *예외적/논쟁적* 톤으로.

## 탐라 4대 핵심 축 (게임 시나리오 우선순위 근거)

| 순위 | 축 | 내용 | 신뢰도 |
|---|---|---|---|
| 1 | **영산강 하구 ↔ 탐라** | 목포·영암·해남 하구권 — 마한·백제계 포구. 구슬·회색토기·곡물·외래 위신재의 재분배 거점. *탐라의 가장 안정적 근접 교역축*. | 중간 (사료 보강 필요하나 고고학 지지) |
| 2 | **가야(김해) ↔ 탐라** | 봉황동·대성동 금관가야 하항. *철·토기·로마유리·일본 출토 가야계 유물*. 5세기 금관가야 약화 후에도 남해 관문성 유지. | **높음** |
| 3 | **대마-이키-무나카타-난바 릴레이** | 일본열도와 연결 시 가장 유력한 4단 경로. 대마·이키는 한반도-규슈 중계, 무나카타는 *제의성 해상 거점*(항구라기보다 항로 통과점), 난바는 5세기 시작·6~7세기 본격화한 외해 관문(창고·공방). | **높음**(난바, 무나카타) / 중간(대마·이키) |
| 4 | **백제 매개 → 남조(건강·광저우)** | 탐라가 받는 중국계 청자(월주요계)·위신재의 *상위 허브*. **직항보다 백제 사단 항로의 다단계 이동품**. 건강은 6조 도성, 광저우는 남조기 대외무역 출발항. | 중간(직항 가능성은 열어두되 *경유*가 기본) |

## 항구 노드 데이터 (시나리오·`data/ports.json` 후보)

대표 좌표·시대·역할만 추렸다. 출처·신뢰도는 자료 원본 표 참조.

| 항구 | 현대 위치 | 역할 | 탐라와의 관계 |
|---|---|---|---|
| **탐라 (제주 북부 포구권)** | 제주시 북부, 용담동·산지천 | 중계 노드 (출발지) | 자기 자신 |
| **영산강 하구** | 목포·영암·해남 | 마한·백제계 재분배항 | **1순위 근접 축** |
| **김해 봉황동/대성동** | 김해시 (고대 김해만) | 가야 하항, 철·국제 위신재 | 2순위, 높은 신뢰도 |
| **대마도** | 나가사키현 쓰시마 | 다항 포구 체계, 한반도-열도 인적·물자 중계 | 일본 릴레이 1단 |
| **이키 (일지국)** | 나가사키현 이키시 (하라노쓰지) | 사절·중계교역 | 일본 릴레이 2단 |
| **무나카타·오키노시마** | 후쿠오카현 무나카타 해역 | *제의성 해상 거점*. 일본·백제·신라계 매납품 | 일본 릴레이 3단(통과점) |
| **난바津** | 오사카시 | 외해 관문. 창고·공방·외교시설 (5세기 개발 시작) | 일본 릴레이 종착 |
| **백제 웅진** | 공주 (금강 하구 경유) | 476년 조공 사절선 도착지 | **시대 앵커 직접 항로** |
| **건강(健康)** | 난징 (양쯔강 하항) | 남조 도성. 비단·문물·제도 발신 | 백제 매개 간접 연결 |
| **광저우(番禺)** | 광저우시 | 남조기 대외무역 출발항. 향료·진주·이역물 | 백제·남해 매개 간접 |
| **흑산도** | 신안군 흑산도 | (자료 외 보조) 단거리 입문용 정박 | 입문 시나리오 근접 |

> **자료가 *간접 연결*로 보는 변연 노드**: 오키나와(패각 원료망), 사할린-오호츠크(북방 해양 자원망). *탐라 직접 도달 증거 없음* — 시나리오에서 직접 항로로 두지 말 것.

## 상품 흐름 — 탐라가 다루는 화물

| 방향 | 품목 | 신뢰도 |
|---|---|---|
| **탐라 ← 들어옴** | 철기, 구슬·장식품, 회색토기, (드물게) 중국계 청자(월주요계) | 고고학 지지, 명확 |
| **탐라 → 나감** | 해산물·패각 가공품·가죽류 (해양 자원 중개 가능성) | **추정** — 사료에 확정 출처 없음. 게임에서도 *추정* 톤 유지 |

→ **게임 적용**:
- 시나리오에 *짐(cargo)* 한 줄 표시 가능 — "철괴 5상자", "패각 한 더미(추정)" 등.
- 단, **무역·경제 시뮬은 비목표**(ROADMAP). 화물은 *동기 부여 텍스트*이지 가격/수익 계산 X.
- 탐라 수출품은 *추정* 표기 의무. "특산: 해산물·패각(추정)" — 사료 정확성 유지가 시대 정합의 일부.

## 시나리오 권장안 (ROADMAP 1.1 갱신 근거)

자료 분석 결과 추천 시나리오 5개 (난이도 순):

1. **탐라 ↔ 흑산도** — 단거리 입문 (자료 외 보조).
2. **탐라 → 영산강 하구(목포·영암 일대)** — 사료 신뢰도 가장 높은 *근접 교역축*. 신규 1순위.
3. **탐라 → 가야 김해** — 높은 신뢰도, 철·국제 위신재 동기. 남해 항로.
4. **탐라 → 북규슈(대마-이키 경유 → 무나카타)** — *경유 릴레이* 구조 명시. 중간 정박지 시나리오 분리도 가능.
5. **탐라 → 백제 웅진** — 476년 조공 사절선 모티프. 시대 앵커 직결.

**난바·건강·광저우·남조 직항은 본 시나리오 1차에 두지 않음** — 사료상 *백제·왜 매개*가 본질이라 다단계 시나리오 또는 후속 확장.

→ ROADMAP 1.1 항로 목록 갱신 반영 (별도 커밋).

## 가드레일 — 사료 정합성 유지

게임 내 시나리오·UI 텍스트 작성 시 다음을 어기지 말 것:

1. **탐라가 *직접* 광저우/남조에 도달했다고 단정하지 말 것**. "백제를 거쳐", "남해 릴레이를 통해" 같은 표현 사용.
2. **탐라 수출품은 항상 *추정* 톤**. "(추정)" 또는 "(전해진다)" 같은 단서 동반.
3. **오키나와·사할린은 직접 항로로 만들지 말 것**. 변연/간접망. 시나리오 후보 X.
4. **대만·북필리핀·동절강 닝보는 후기 5세기 항만 실체 약함** — 사용 보류.
5. **울산 반구동은 통일신라 비중**, 5세기 후반 시나리오에 사용하지 말 것.

## 네트워크 구조 도식 (자료 원본의 mermaid 단순화)

```
[남사할린] -.-.-.- (간접) -.-.-.-> [난바]
[오키나와] -.-.-.- (간접) -.-.-.-> [난바]

[난바]──[무나카타]──[이키]──[대마도]──[김해/가야]──[탐라]
                                              ↑
                                         [영산강 하구]
                                              ↑
                                          [탐라]
                                              ↑ (백제 매개)
                                          [건강]──[광저우]──[합포]──[루이러우]──[투본]──[오케오]
```

게임 내에서 플레이어는 이 그래프 *한 엣지*씩 이동. 5세기 항해사가 *실제로* 그랬듯이.

- **매우 높음**: 국립제주박물관 자료, 《梁書》 권54

→ 게임 텍스트에서 *높음/매우 높음* 항목은 단정형, *중간/보조*는 추정형.
